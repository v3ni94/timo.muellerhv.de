# Porträts Timo Müller

Hier ausschließlich freigegebene, echte Porträts von Timo Müller ablegen (Fotograf und Nutzungsrechte in docs/BILDER-LIZENZEN.md eintragen). Keine Stockfotos, keine KI-Bilder, keine fremden Personen.

Erwartete Dateinamen (JPG oder PNG, mindestens 1600 px auf der langen Seite):

| Datei | Einsatz | Seitenverhältnis |
|---|---|---|
| portrait-1.jpg | Startseite Hero, Profil Hero | 4:5 (Hochformat) |
| portrait-2.jpg | Startseite Abschnitt "Persönlicher Ansatz", Kontakt | 3:2 (Querformat) oder 1:1 |
| portrait-3.jpg | Profil, zweites Bild (Arbeitssituation) | 3:2 (Querformat) |

Fehlt eine Datei, rendert die Komponente automatisch einen typografischen Platzhalter mit identischem Seitenverhältnis. Nach dem Ablegen neu bauen (`npm run build`).
